## English

This repository has been **renamed from `thaliox/thaliox` to [`thaliox/thaliox-os`](https://github.com/thaliox/thaliox-os)**.

**Why:** to give every repository under the `thaliox` organization a clear, purpose-specific name. `thaliox/thaliox` was ambiguous — it could mean the org, the brand, or any one of its projects. `thaliox/thaliox-os` says exactly what it is: **the operating system built for AI**.

All development, issues, and releases now live in the new repository. Please update your bookmarks, remotes, and links:

```sh
git remote set-url origin https://github.com/thaliox/thaliox-os.git
```

👉 **Go to the active repository: [github.com/thaliox/thaliox-os](https://github.com/thaliox/thaliox-os)**
